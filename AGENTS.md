# Project instructions

Read README.md and docs/project-brief.md before implementation.

- Prioritise the single-PDF workflow and preservation of supporting passages and page numbers.
- Never present a model suggestion as researcher-approved.
- Represent unsupported fields as missing, rather than inventing values.
- Use local inference by default; do not add a required cloud service.
- Preserve original machine suggestions when recording researcher edits.
- Keep real inputs and outputs under local/ and out of commits.
- Do not download large models or change machine-wide settings without a task requirement.
- Add meaningful tests and CI with the first executable implementation.
- Report limitations and measured checks plainly. Do not claim accuracy from synthetic examples.
